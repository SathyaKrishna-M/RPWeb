# RPWeb

Story-first roleplay platform for worlds, characters, scenes, arcs, relationships, lore, and timelines.

## Project Priorities

- Simplicity
- Story immersion
- Mobile responsiveness
- Fast UI

## Scripts

```powershell
npm run dev
npm run typecheck
npm run prisma:validate
```

## Structure

- `src/app` - Next.js App Router pages and route groups
- `src/components` - reusable UI, layout, and storytelling components
- `src/server` - backend modules, services, repositories, permissions, jobs, and realtime boundaries
- `src/lib` - shared helpers and configuration
- `src/types` - shared TypeScript types
- `prisma` - database schema and migrations
