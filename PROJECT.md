# RP Website Vision

## Core Philosophy

The website should feel like participating in a story, not a Discord server.

Goals:
- Easy to understand
- Immersive
- Character-driven
- Scene-based roleplay
- Minimal clutter

## Core Entities

### Worlds
- Lore
- Rules
- Timeline
- Character list

### Characters
- Multiple characters per user
- Character profilesv
- Character switching

### Scenes
- Scene-based roleplay
- Public/private scenes
- RP formatting tools

### Relationships
- Friend
- Rival
- Family
- Enemy
- Lover
- Ally

### Story Features
- Story arcs
- Character journals
- World timeline

## Future Features
- Interactive map
- AI summaries
- Character memories
- Scene artwork generation

## Features NOT Included
- Scene music
- Reputation system
